Exercice soumis — Algorithmique

function somme(n) {
  let s = 0;
  for (let i = 0; i <= n; i++) {
    s = s + i;
  }
  return s
}

Correction IA — OpenRouter

Logique correcte

La boucle calcule bien la somme de 0 à n. Le résultat est exact.

Point d'amélioration

Il manque un point-virgule après return s. En JS strict cela peut poser problème.

Optimisation possible

La formule n*(n+1)/2 donne le même résultat en O(1) au lieu de O(n).
